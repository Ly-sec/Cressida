---
title: Keyboard shortcuts
description:
  Useful shortcuts for composing messages, completion and media viewing.
---

Shortcuts act on the current field, picker or viewer. An open overlay takes
priority over the chat behind it.

## Composer

When no control has focus in a chat, pressing a key focuses the composer. Your
first character is included in the draft. Shortcuts, Tab navigation and Escape
keep their usual actions, and open overlays or editors take priority.

| Shortcut        | Action                                             |
| --------------- | -------------------------------------------------- |
| Enter           | Send the message.                                  |
| Shift+Enter     | Insert a new line.                                 |
| Ctrl+V          | Paste text or an available clipboard image.        |
| Ctrl+A          | Select text in the active input.                   |
| Ctrl+C / Ctrl+X | Copy or cut selected input text.                   |
| Ctrl+Z          | Undo an edit in the input.                         |
| Escape          | Cancel a reply, after dismissing any open overlay. |

## Suggestions and controls

| Shortcut        | Action                                    |
| --------------- | ----------------------------------------- |
| Up / Down       | Move through open completion suggestions. |
| Enter / Tab     | Choose a suggestion without sending.      |
| Escape          | Dismiss completion.                       |
| Tab / Shift+Tab | Move between focusable native controls.   |

## Message search

| Shortcut    | Action                                         |
| ----------- | ---------------------------------------------- |
| Ctrl+F      | Open message search.                           |
| Up / Down   | Highlight a search filter or value.            |
| Enter / Tab | Accept the highlighted suggestion.             |
| Enter       | Search when no suggestion is highlighted.      |
| Escape      | Dismiss search suggestions and keep the query. |

See [Search messages](chat.md#search-messages) for filters and examples.

## Inbox

| Shortcut            | Action                                         |
| ------------------- | ---------------------------------------------- |
| Ctrl+I              | Open or close the inbox.                       |
| Left / Right        | Change inbox tabs.                             |
| Up / Down           | Scroll the inbox.                              |
| Page Up / Page Down | Scroll a page.                                 |
| Escape              | Cancel reminder choices, then close the inbox. |

See [Inbox](inbox.md) for unread conversations, mentions, bookmarks and
reminders.

## Voice chat

| Shortcut         | Action                                          |
| ---------------- | ----------------------------------------------- |
| Ctrl+Shift+Space | Hold to transmit when Push to talk is selected. |

Change the shortcut under **Keybinds**. It works while Cressida has keyboard
focus; switching windows or hiding Cressida releases it. See
[Voice chat](voice.md) for activation and microphone settings.

## Image viewer

| Shortcut     | Action                  |
| ------------ | ----------------------- |
| Left / Right | Previous or next image. |
| + / -        | Zoom in or out.         |
| 0            | Reset zoom to 100%.     |
| Ctrl+C       | Copy the current image. |
| Escape       | Close the viewer.       |

## Video player

| Shortcut     | Action                                       |
| ------------ | -------------------------------------------- |
| Space        | Play or pause.                               |
| Left / Right | Seek backward or forward.                    |
| M            | Mute or unmute.                              |
| F            | Toggle the expanded view.                    |
| Escape       | Leave the expanded view or close the player. |
