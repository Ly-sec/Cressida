---
title: Keyboard shortcuts
description:
  Useful shortcuts for composing messages, completion and media viewing.
---

Shortcuts act on the current field, picker or viewer. An open overlay takes
priority over the chat behind it.

## Composer

| Shortcut        | Action                                             |
| --------------- | -------------------------------------------------- |
| Enter           | Send the message.                                  |
| Shift+Enter     | Insert a new line.                                 |
| Ctrl+V          | Paste text or an available clipboard image.        |
| Ctrl+A          | Select text in the active input.                   |
| Ctrl+C / Ctrl+X | Copy or cut selected input text.                   |
| Ctrl+Z          | Undo an edit in the input.                         |
| Escape          | Cancel a reply, after dismissing any open overlay. |

## Suggestions and controls

| Shortcut        | Action                                    |
| --------------- | ----------------------------------------- |
| Up / Down       | Move through open completion suggestions. |
| Enter / Tab     | Choose a suggestion without sending.      |
| Escape          | Dismiss completion.                       |
| Tab / Shift+Tab | Move between focusable native controls.   |

## Image viewer

| Shortcut     | Action                  |
| ------------ | ----------------------- |
| Left / Right | Previous or next image. |
| + / -        | Zoom in or out.         |
| 0            | Reset zoom to 100%.     |
| Ctrl+C       | Copy the current image. |
| Escape       | Close the viewer.       |

## Video player

| Shortcut     | Action                                       |
| ------------ | -------------------------------------------- |
| Space        | Play or pause.                               |
| Left / Right | Seek backward or forward.                    |
| M            | Mute or unmute.                              |
| F            | Toggle the expanded view.                    |
| Escape       | Leave the expanded view or close the player. |
